=== Coinvera Returns ===
Requires at least: 5.8
Requires PHP: 7.4
Stable tag: 1.0.0

Portail client en libre-service pour les retours et échanges WooCommerce, avec avoir immédiat (bonus inclus) ou remboursement soumis à validation.

== Description ==
* Onglet « Retours » dans Mon compte : le client choisit sa commande, les articles concernés et la raison, en deux clics.
* Avoir immédiat avec bonus (taux réglable) : un bon d'achat est généré et envoyé par e-mail instantanément, sans action du marchand.
* Remboursement ou échange : la demande est soumise à votre validation (le remboursement réel reste sous votre responsabilité, car ce plugin fonctionne avec n'importe quelle passerelle de paiement).
* Empêche de réclamer plus que ce qui a été acheté, même en plusieurs demandes.
* Journal complet des demandes, export/effacement RGPD.
* Même licence que les autres plugins Coinvera.

== Installation ==
1. WooCommerce doit être installé et activé.
2. Extensions > Ajouter > Téléverser le fichier ZIP, puis activer (l'onglet « Retours » apparaît automatiquement dans Mon compte).
3. Coinvera Returns > Réglages : licence, délai de retour, bonus sur l'avoir.
